# Panorama Site Builder Pro

Профессиональный клиентский билдер для создания красивых, быстрых и полностью автономных сайтов с виртуальными 360° турами.

## Ключевые возможности

- Множественная загрузка панорам с автосортировкой по имени файла
- Drag & drop сортировка сцен + нумерация
- Живой предпросмотр на базе Pannellum
- Визуальный редактор хотспотов (клик по панораме + удобное модальное окно)
- Гибкая кастомизация: 5 пресетов тем + полная настройка цветов, шрифтов, прозрачности
- Модули: карусель (снизу/сбоку), логотип, кнопка «Об аудитории», информационные карточки, мини-карта, автоповорот, звуковое сопровождение, прогресс-бар
- Экспорт полностью готового сайта в ZIP (index.html + panoramas/)
- Оптимизация изображений при экспорте (3 уровня качества)
- Автосохранение в localStorage + скачивание/загрузка проекта (.json)
- Современный SaaS-интерфейс с индикатором сохранения

## Запуск

```bash
cd panorama-site-builder
python -m http.server 8080
```

Откройте http://localhost:8080

## Экспорт

Нажмите **🚀 Экспорт сайта** — получите ZIP-архив. Загрузите на любой хостинг. Сайт полностью автономный (Pannellum подключается с CDN).
